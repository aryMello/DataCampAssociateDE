# 📊 DataCamp Associate Data Engineer Track

Welcome! This repository documents my journey through the **DataCamp Associate Data Engineering in SQL** career track a structured program focused on relational database design, data querying, and analytics.

This track helped me build a solid foundation in SQL, warehousing, and database architecture with hands-on projects and query-driven insights from real datasets.

---

### 🧰 Topics Covered
1. Understanding Data Engineering  
2. Introduction to SQL  
3. Intermediate SQL  
4. Joining Data in SQL  

🧪 **Project 01: Analyzing Student Mental Health**  
Explored correlations in student well-being using SQL aggregations, filters, and joins.

5. Relational Databases in SQL  
6. Database Design & Schema Modeling  
7. Data Warehousing Concepts  
8. Introduction to Snowflake  
9. Data Visualization Techniques  

🚉 **Project 02: Exploring London’s Travel Network**  
Built queries to analyze transit trends, passenger flows, and station usage with real-world complexity.

---

### 🧠 Skills Gained

- Writing advanced SQL queries with joins, windows, and subqueries  
- Designing star schemas for reporting use cases  
- Applying relational concepts (PKs, FKs, normalization)  
- Extracting insights from messy, large-scale tabular data  
- Presenting analytics-ready outputs with basic dashboard concepts
